Other non-string, non-BigInt values are coerced to numbers:

false + false; // 0

Addition using BigInts
1n + 2n; // 3n

You cannot mix BigInt and number operands in addition.
1n + 2; // TypeError: Cannot mix BigInt and other types, use explicit conversions
2 + 1n; // TypeError: Cannot mix BigInt and other types, use explicit conversions
"1" + 2n; // TypeError: Cannot mix BigInt and other types, use explicit conversions

To do addition with a BigInt and a non-BigInt, convert either operand:
1n + BigInt(2); // 3n
Number(1n) + 2; // 3

If one of the operands is a string, the other is converted to a string and they are concatenated:
"foo" + "bar"; // "foobar"
5 + "foo"; // "5foo"
"foo" + false; // "foofalse"
"2" + 2; // "22"

Why use setTimeout(fn, 0)?
To defer execution until the call stack is clear.
Useful when you don’t want to block UI updates, rendering, or other event handlers.
Helps break up heavy tasks into smaller chunks (avoid “freezing” the page).
Sometimes used to ensure code runs after DOM updates or after promises.

Event Loop Basics (simplified)

Call stack → runs your current synchronous code.
Microtask queue → things like Promise.then, queueMicrotask.
Macrotask (task) queue → things like setTimeout, setInterval, setImmediate (Node), UI events.

Order of execution:

Run all synchronous code (stack).
Flush all microtasks (until empty).
Take one macrotask → run it → go back to step 2.

var, let, and const
1. Scope
var → Function-scoped (or global if not inside a function).
let & const → Block-scoped (inside { ... }).

2. Hoisting
All are hoisted to the top of their scope, but:
var → hoisted and initialized with undefined.
let & const → hoisted but not initialized (they live in the temporal dead zone until execution reaches their declaration).

3. Re-declaration
var → Can be redeclared in the same scope.
let & const → Cannot be redeclared in the same scope.

4. Re-assignment
var → Allowed.
let → Allowed.
const → Not allowed (value cannot be reassigned).
For const objects/arrays, you can mutate properties/elements, but you can’t reassign the variable itself.

5. Global Object Binding
var → Declared in the global scope, attaches to window (in browsers).
let & const → Do not attach to the global object.

//async await
Async/await is a programming pattern for writing non-blocking, asynchronous code in a style similar to synchronous code, allowing programs to handle long-running tasks without freezing.
// An async function
async function getData() {
  try {
    let response = await fetch("https://api.example.com/data"); 
    // execution waits here until fetch resolves
    let data = await response.json(); 
    console.log(data); // Use the data
  } catch (error) {
    console.error("Error fetching data:", error);
  }
}
